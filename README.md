# MyCar+ Web V6.4

## Νέα στο V6.4
- Δέχεται οποιαδήποτε φωτογραφία από Βιβλιοθήκη ή Κάμερα.
- Αυτόματο κεντρικό crop σε τετράγωνη εικόνα.
- Αυτόματο resize στα 600 × 600 px.
- Αυτόματη συμπίεση JPEG πριν την αποθήκευση.
- Δεν εμφανίζεται πλέον η φωτογραφία σε υπερβολικά μεγάλο μέγεθος.
- Η φωτογραφία εμφανίζεται μέσα στο μικρό εικονίδιο/avatar του κάθε οχήματος.
- Αν δεν υπάρχει φωτογραφία, εμφανίζεται το αντίστοιχο εικονίδιο τύπου οχήματος.
- Η ίδια επεξεργασμένη φωτογραφία χρησιμοποιείται στην αναλυτική προβολή και όπου αλλού εμφανίζεται το όχημα.
- Διατηρούνται όλες οι λειτουργίες του V6.3.
