# MyCar+ Web V6

## Νέα στο V6
- Πολύ πιο απλή και γρήγορη καταχώριση οχήματος.
- Μεγάλα εικονίδια επιλογής τύπου οχήματος.
- Μόνο ο τύπος είναι απαραίτητος· όλα τα άλλα στοιχεία είναι προαιρετικά.
- Χειροκίνητη καταχώριση χωρίς υποχρεωτική άδεια ή έγγραφο.
- Φωτογραφία από κάμερα ή συλλογή.
- Έως δύο ιδιοκτήτες με ονοματεπώνυμο και τηλέφωνο.
- Ασφάλεια, ΚΤΕΟ και service σε προαιρετικές ενότητες.
- Δημιουργία / κοινοποίηση PDF για κάθε όχημα μέσω της εκτύπωσης του browser.
- Στο iPhone: στην εκτύπωση άνοιξε την προεπισκόπηση και πάτησε Κοινοποίηση για αποστολή PDF.
- Backup, dark mode, PWA και offline λειτουργία.
- Αυτόματη μεταφορά δεδομένων από προηγούμενες εκδόσεις όπου είναι διαθέσιμα.
