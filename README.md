# MyCar+ Web V6.1

## Νέα στο V6.1
- Η φωτογραφία οχήματος μπορεί να επιλεγεί από τη Βιβλιοθήκη φωτογραφιών ή την Κάμερα.
- Δεν επιβάλλεται πλέον άνοιγμα μόνο της κάμερας.
- Νέα προαιρετική ενότητα «Χαρακτηριστικά οχήματος».
- Κυβισμός, ιπποδύναμη, καύσιμο, κιβώτιο, κίνηση, εργοστασιακή κατανάλωση, αμάξωμα και θέσεις.
- Κουμπί αναζήτησης χαρακτηριστικών στο διαδίκτυο με βάση μάρκα / μοντέλο / έτος.
- Τα χαρακτηριστικά εμφανίζονται και στην καρτέλα οχήματος.
- Τα χαρακτηριστικά περιλαμβάνονται και στο PDF.
- Όλα τα πεδία παραμένουν προαιρετικά.

## Σημείωση για αυτόματη συμπλήρωση από Internet
Το V6.1 ανοίγει σχετική αναζήτηση στο διαδίκτυο. Για πλήρη αυτόματη συμπλήρωση χαρακτηριστικών μέσα στην εφαρμογή χρειάζεται σύνδεση με εξωτερικό Vehicle Data API ή backend.
