# MyCar+ Web V6.7

## Αρχική σελίδα
- Τα αποθηκευμένα οχήματα εμφανίζονται πρώτα, αμέσως κάτω από το header.
- Κάθε αποθηκευμένο όχημα φαίνεται με τη μικρή φωτογραφία του.
- Πατώντας την κάρτα ή τη φωτογραφία ανοίγει η καρτέλα του οχήματος.
- Το «+ Νέο όχημα» εμφανίζεται ακριβώς κάτω από τα αποθηκευμένα οχήματα.
- Μετά ακολουθούν τα στατιστικά και οι υπενθυμίσεις.
- Σε κινητό η αναζήτηση/φίλτρο κρύβονται ώστε η αρχική να είναι καθαρή όπως στο mockup.
- Νέο service-worker cache ώστε να μη μένει η παλιά αρχική του GitHub Pages/PWA.

Ανέβασε όλα τα αρχεία στο ίδιο GitHub Pages repository και αντικατάστησε τα προηγούμενα.
